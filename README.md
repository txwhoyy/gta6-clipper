A vertical YouTube Short cut from raw GTA 6 gameplay: a five-star police chase along Vice Ocean Beach in Leonida that builds and builds — until it suddenly, spectacularly doesn't. The chase opens the clip, and a short closing card pitches make.fun: viewers can make clips like this with AI and earn money there. The published video is named in `VIDEO.json`; `main.ts` validates that address and hands the file to the grader.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
